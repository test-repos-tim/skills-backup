## Data Sources (Auto-Aggregated)
- `~/.hermes/ai-sec-career/certifications.yaml` → Cert Tracker
- `~/.hermes/ai-sec-career/learning-path.yaml` → Learning Progress
- `~/.hermes/ai-sec-career/projects/` → Project Portfolio
- `~/.hermes/ai-sec-career/linkedin-posts.yaml` → LinkedIn Metrics
- `~/.hermes/ai-sec-career/job-applications.yaml` → Job Pipeline
- `~/.hermes/ai-sec-career/skill-assessment.yaml` → Skill Radar

## Readiness Score Algorithm
```
READINESS = weighted_sum(
  certifications: 25%    # Tier 1 certs = 100%, Tier 2 = 50%, Tier 3 = 20%
  learning: 20%          # Phase completion % 
  projects: 20%          # Completed projects / 5 target
  linkedin: 10%          # Consistency score (posts/week * engagement)
  pipeline: 15%          # Applications * stage weight
  skills: 10%            # Self-assessment avg / 5
)
```

## Usage Commands

```bash
# Show full dashboard
hermes skill run ai-sec-progress-dashboard --action=show

# Show specific view
hermes skill run ai-sec-progress-dashboard --action=view --section=certifications
hermes skill run ai-sec-progress-dashboard --action=view --section=pipeline

# Update manual data
hermes skill run ai-sec-progress-dashboard --action=update --section=skills --skill="Adversarial ML" --value=4

# Export dashboard (JSON for external tools)
hermes skill run ai-sec-progress-dashboard --action=export --format=json

# Generate weekly review report
hermes skill run ai-sec-progress-dashboard --action=weekly-report

# Set readiness target
hermes skill run ai-sec-progress-dashboard --action=target --readiness=85 --by-week=20
```
